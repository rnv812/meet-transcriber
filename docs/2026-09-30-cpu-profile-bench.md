# Замер профилей cuda / cpu (30.09.2026)

Машина: RTX 5070 Ti, Windows 11. Встреча: 37:44 (2264 с), 3 спикера. Запуск:
`meet transcribe ... --speakers 3` с кодом ветки (`PYTHONPATH=src`). CPU-прогоны —
с `CUDA_VISIBLE_DEVICES=-1`, чтобы выравнивание (wav2vec2) и pyannote тоже шли на
CPU: так имитируется машина без NVIDIA.

## Как мерили

Полный CPU-прогон на 37 минутах оказался слишком долгим, поэтому все три профиля
сравнены на одном и том же 6-минутном фрагменте (первые 360 с встречи,
`ffmpeg -t 360 -c copy`). На коротком фрагменте загрузка моделей занимает большую
долю времени, поэтому коэффициенты ниже слегка завышены относительно длинных
записей (оценка в UI получается с запасом). Для сверки CUDA прогнан и на полной
записи.

## Результаты

Время — полное (загрузка моделей + распознавание + выравнивание + диаризация).
Коэффициент = время / длительность аудио.

| Профиль | Модель | Аудио | Время | Коэффициент |
|---|---|---|---|---|
| cuda (float16) | `bzikst/faster-whisper-large-v3-russian`* | 360 с | 80 с | **0.22** |
| cuda (float16), сверка | то же | 2264 с | 424 с | 0.19 |
| cpu (int8) | `deepdml/faster-whisper-large-v3-turbo-ct2` | 360 с | 339 с | 0.94 |
| cpu (int8) | `Systran/faster-whisper-medium` | 360 с | 455 с | **1.26** |

\* модель CUDA-профиля — из настройки `asr.model` по умолчанию.

Первый прогон medium занял 582 с, но включал скачивание модели (~1.5 ГБ); в таблице
— повторный прогон с прогретым кэшем. Turbo к моменту замера уже лежал в кэше.

Разница между CPU-моделями 455 / 339 = 1.34x, то есть меньше порога 1.5x из плана.
По критерию выбора берём ту, где три проверенных места читаются без искажения смысла.

## Качество

Эталон: ручная правка транскрипта той же встречи, три контрольных места (обращение по имени, короткая реплика, длинная фраза). CPU-модели не ставят пунктуацию и регистр, поэтому сравнивался смысл. cuda совпадает с эталоном почти дословно; turbo искажает смысл в двух местах из трёх; medium сохраняет смысл во всех трёх.

## Выбор

CPU-модель — **`Systran/faster-whisper-medium`**: медленнее turbo лишь в 1.34x
(< 1.5x), зато в двух из трёх мест turbo искажает смысл, а medium нет.
`asr.CPU_MODEL_NAME` заменён соответственно.

`SPEED_FACTOR = {"cuda": 0.22, "cpu": 1.26}` (время на фрагменте / 360 с).
Это оценка для UI, а не обещание. Ожидаемое время для часовой записи на CPU
без NVIDIA — около 75 минут.
