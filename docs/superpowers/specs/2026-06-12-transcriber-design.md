# Локальный транскрибатор встреч — дизайн

Дата: 2026-06-12. Статус: утверждён.

## Цель

Локальный инструмент (Windows 11, RTX 5070 Ti 16 ГБ): записать звук рабочей встречи
и получить markdown-транскрипт с разделением по говорящим, чтобы делиться с коллегами.
Всё работает локально, данные наружу не уходят. Язык встреч — русский.
Приоритет — качество результата.

## Команды (CLI)

### `meet record`

- Пишет одновременно две дорожки через WASAPI (pyaudiowpatch):
  - системный звук (loopback — голоса коллег из наушников);
  - микрофон (голос пользователя).
- Остановка по Ctrl+C.
- Результат: `recordings/YYYY-MM-DD_HH-MM/` с `sys.wav` и `mic.wav`.
- wav пишется потоково: при сбое посреди встречи записанное остаётся на диске.
- Платформа созвона не важна — захват на уровне Windows.

### `meet transcribe <путь>`

- Вход: либо папка нашей записи (две дорожки), либо одиночный аудио/видеофайл
  (mp3/m4a/wav/mp4/mkv...; звук извлекается ffmpeg).
- Двухдорожечный режим: mic.wav распознаётся как один говорящий («Вы»);
  sys.wav распознаётся и делится на говорящих диаризацией; реплики сливаются
  по таймкодам в общую ленту.
- Однофайловый режим: распознавание + диаризация по всей записи.
- Выход: markdown рядом с записью.

## Формат результата

```markdown
# Встреча 2026-06-12 15:30
Длительность: 47 мин

**[00:00:12] Вы:** Коллеги, начнём...
**[00:00:25] Спикер 1:** Да, по первому вопросу...
```

- Подряд идущие реплики одного говорящего склеиваются.
- Имена спикеров пользователь правит в md (флаг `--names` — возможное развитие).

## Технологии

- Python 3.12, виртуальное окружение.
- ASR: faster-whisper, модель large-v3, язык фиксирован `ru`.
- Диаризация: pyannote.audio 3.1 (нужен бесплатный токен HuggingFace, один раз).
- Захват звука: pyaudiowpatch (WASAPI loopback + микрофон).
- Конвертация: ffmpeg.
- GPU: RTX 5070 Ti — архитектура Blackwell (sm_120), нужен PyTorch с CUDA 12.8+.
  16 ГБ хватает на ASR и диаризацию одновременно.

## Обработка ошибок

- Понятные сообщения: нет ffmpeg, нет токена HF, недоступен GPU.
- При нехватке видеопамяти — автоматический переход на квантованную модель (int8).
- Падение транскрипции не трогает исходную запись.

## Проверка

- Тестовая запись 30–60 сек (звук + своя речь) → прогон → таймкоды и спикеры сверяются глазами.
- Прогон стороннего одиночного файла тем же путём.
- Ориентир скорости: ~3–5 мин на час записи.

## Вне рамок первой версии

- Живая транскрипция во время встречи (возможный следующий этап).
- Саммари/протокол поверх транскрипта.
- Веб-интерфейс, слежение за папкой, именование спикеров по образцам голоса.
