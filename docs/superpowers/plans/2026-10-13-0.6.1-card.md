# 0.6.1 «Расшифровка» без перегрузки — план

> Исполнение: в этой сессии, без субагентов (решение владельца). Шаги — `- [ ]`.

**Цель:** вкладка «Расшифровка» по спецификации — тихая шапка, инструменты в
строке вкладок, легенда-фильтр, сценарий с сериями, наблюдения под репликой,
карта разметки в цвет акцента.

**Спецификация:** `docs/superpowers/specs/2026-10-13-0.6.1-card-and-mac-mic-design.md`
(часть 1). Часть 2 (macOS) ждёт журналов — отдельно.

**Стек:** React + TypeScript (Vite, Vitest), CSS на токенах Atlas Aurora.

## Общие ограничения

- Только `var(--…)` токены Aurora; стражи `app/src/theme/*.test.ts` и
  `app/src/lib/webkit.test.ts` зелёные; корневой класс блока — в одном файле.
- Тексты интерфейса — по-русски; доступность: роли, подписи, клавиатура.
- Все три набора тестов зелёные (Python, окно, оболочка).
- Поведение, которое не меняется: поиск (правила, «2 из 5», Enter/Shift+Enter,
  Esc), переход по времени, правка и выбор реплик, «Разделить», «Спросить
  агента», плеер и «Только важное», переход из поиска по записям.

## Что проверить отдельно (не покрыто прямыми тестами задач)

1. Ctrl+F с вкладок «Итоги»/«Агент» открывает поиск на «Расшифровке» (строка
   поиска теперь скрыта по умолчанию).
2. «Исправить…» из строки вкладок не снимает выделение в реплике.
3. Фильтр «Наблюдения» вместе с фильтром типа — объединение, а не пересечение.
4. Серия не тянется через «… N реплик» и через перерыв (`kind: "break"`).
5. Текст до спикеров (`textPhase`): без серийных имён «Спикер ?», без легенды.
