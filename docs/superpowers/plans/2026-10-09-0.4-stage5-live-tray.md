# Meet 0.4 · Этап 5 «Живая панель и трей»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** окно ассистента на встрече (развёрнутое и свёрнутое) и панель записи
под значком трея/строки меню — на Atlas Aurora по макетам `MeetLive`,
`MeetLiveMini`, `MeetTray`, `MacDesktop`, `MacMeeting`; трей следует теме и
палитре из «Оформления». Поведение 0.3.7 сохраняется.

**Spec:** `docs/superpowers/specs/2026-10-08-0.4-atlas-aurora-design.md`, «Решения → 5»
и «Расхождения с макетами» (живая панель; свёрнутая ошибка запуска — делаем;
карточка «Подсказка» с черновиком и подсветка строки с вопросом — не делаем).
Макеты — `$MOCK` (см. план этапа 3): `MeetLive.dc.html`, `MeetLiveMini.dc.html`,
`MeetTray.dc.html`, `MacDesktop.dc.html`, `MacMeeting.dc.html`.

## Global Constraints

- Все ограничения этапа 3 (`docs/superpowers/plans/2026-10-09-0.4-stage3-main-window.md`,
  «Global Constraints») — здесь действуют для `app/src/live/*` и `app/src/tray/*`.
- Окна `live` и `tray-panel` прозрачные: фон рисует их корневой блок (`glass
  glass--dense` + `glass-line` + `elev-3`, радиус `r-lg`/`r-xl`); `body` — прозрачный.
- Трей больше не держит свой набор токенов (`--tp-*` на `prefers-color-scheme`):
  только токены Aurora и тема/палитра из настроек (`useAppearance` уже подключён).
  `[data-glass="native"]` на macOS сохраняется: фон — системный vibrancy,
  страница рисует только содержимое (корень без своей заливки).
- Тексты 0.3.7 сохраняются (диалог отмены — «Остановить без сохранения?» /
  «Удалить запись», `lib/recordingStop.ts`).
- Нативное меню трея (Rust `tray.rs`) не меняется.
- Тесты: `LiveChat.test.tsx.snap` — переснимается осознанно (`npx vitest run src/live/LiveChat.test.tsx -u`,
  просмотреть diff, закоммитить с LF-переводами строк как есть в репозитории).
