# Meet 0.4 · Этап 6 «Знак и иконки»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** значок приложения, установщика, ярлыков, favicon, значки трея (5
состояний × 4 размера) и шаблоны строки меню macOS нарисованы новым знаком
Meet — вариант B «Диск с сердцевиной» на фиолетовом сиянии Atlas Aurora.

**Architecture:** источник истины остаётся `scripts/make_app_icons.py`
(геометрия и цвета в одном файле; растры рисуются заново под каждый размер
с точным сглаживанием; SVG-мастер `app/src-tauri/icons/source/meet.svg` =
`app/public/favicon.svg`). Меняются только геометрия (кольцо → диск с малой
сердцевиной) и цвета (Linear-индиго → фиолетовая палитра Aurora, значения
oklch из токенов дизайн-системы, перевод в sRGB — в скрипте).

**Spec:** `docs/superpowers/specs/2026-10-08-0.4-atlas-aurora-design.md`, «Решения → 6».
Образец вида: `docs/superpowers/specs/assets/2026-10-08-logo-variants.html`, вариант B.

## Global Constraints

- Комментарии и docstring — на русском.
- Знак B: плитка Chaos Black `#0f0f0f` с тонкой светлой кромкой (`oklch(100% 0 0 / .09)`,
  ~2/256 стороны), радиус скругления — как сейчас; диск: внешний радиус 78/256
  стороны плитки, сердцевина — круг радиусом 18/256 цвета плитки (у значка —
  `#0f0f0f`, не прозрачный).
- Сияние диска — фиолетовая палитра Aurora (oklch L C H): abyss (20% 0.06 290),
  deep (34% 0.11 292), mid (46% 0.16 295), signal (75% 0.12 300), crest (81% 0.10 325),
  ice (93% 0.04 315): основа `mid`, мягкие пятна `signal` (сверху слева), `crest`
  (сверху справа), блик `ice`, тень `abyss` снизу слева, глубина `deep` снизу справа;
  зерно — только от 64 px, детерминированное (фиксированный seed), едва заметное.
- 16–48 px: без зерна и без размытия пятен до каши — упрощённый радиальный
  градиент signal → mid → deep; диск крупнее (поля меньше), сердцевина видна на 16 px
  (не меньше ~2 px в диаметре).
- Трей (16/20/24/32, Windows), 5 состояний, различимы на 16 px не только цветом:
  `idle` — диск приглушённый (без сияния, нейтрально-фиолетовый серый);
  `recording` — яркий диск + точка `danger` (oklch 72% 0.16 25) в правом нижнем
  углу с прозрачным вырезом вокруг; `live` — яркий диск, сердцевина светлая (`ice`)
  вместо тёмной; `busy` — диск с вырезанным сектором (как нынешняя дуга);
  `offline` — приглушённый диск + янтарная точка `warning` (oklch 84% 0.14 82).
- Шаблоны строки меню macOS (18/36): одноцветные (чёрный + альфа), те же формы;
  `offline` — бледнее (как сейчас), состояния различаются формой.
- Цвета значка не зависят от палитры пользователя (всегда фиолетовый).
- Тесты не ходят в сеть; растры детерминированы.
- Параллельная работа: этот этап идёт одновременно с этапом 3 в том же
  worktree. Коммитить ТОЛЬКО свои пути (`scripts/make_app_icons.py`,
  `app/src-tauri/icons/`, `app/public/favicon.svg`, `tests/test_app_icons.py`) —
  `git add <пути>`, никогда `git add -A`/`.`; не запускать `npm test`/vitest
  (их гоняет этап 3); при `index.lock` — подождать и повторить.
