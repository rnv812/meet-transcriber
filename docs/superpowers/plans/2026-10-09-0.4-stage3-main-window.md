## Решения этапа (контролёр)

- Рейка — фиксированные 60 px (режим «навигация шире/уже» уходит; `ShellResize`
  для рейки убирается, ширина списка остаётся изменяемой, по умолчанию 300).
- Шапка окна (`topbar`) уходит: кнопка записи и её меню — в рейку (меню —
  поповер справа от кнопки), предупреждения шапки («Мало места», подмена
  устройства, системный звук macOS) — на страницу «Идёт запись» и значком с
  подсказкой внизу рейки (`IconButton` с `tooltip`, цвет `--warning`, по клику —
  то же, что сейчас).
- Группы записей — вверх списка: `select-btn--md` «Все записи ▾» (имя текущей
  группы) открывает поповер с деревом групп (то же дерево `GroupsNav`, тот же
  drag-and-drop, меню группы, «Новая группа»).
- Вкладки карточки — Aurora `.tabs` (класс окна `card-tabs` остаётся для раскладки
  панели); точка «агент работает» — 6 px `--accent`.
- Панель «Спикеры» — `drawer` 420 (правый, на стекле; ширину по-прежнему можно
  менять, если сейчас можно), «Улучшить расшифровку» — лист 560 по центру
  (`sheet` на `backdrop--modal`) — с прежней логикой.
- Не делаем (нужен бэкенд — спек): имя программы звонка, названия устройств,
  строки расшифровки по ходу распознавания, таймкоды у решений в итогах,
  «Последний раз», общий «Неизвестный голос».
