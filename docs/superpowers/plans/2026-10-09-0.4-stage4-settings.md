# Meet 0.4 · Этап 4 «Настройки»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** настройки перегруппированы: 5 групп меню и ~17 узких разделов,
подгруппы-карточки внутри раздела, «Тонкая настройка» для редкого, поиск по
настройкам, «Анализ встречи» одной таблицей «размечать / показывать»; всё на
компонентах Atlas Aurora. Ключи `config.json`, API и поведение — прежние.

**Spec:** `docs/superpowers/specs/2026-10-08-0.4-atlas-aurora-design.md`, «Решения → 4»
(таблица групп и разделов, «Тонкая настройка», таблица «Анализ встречи», поиск,
совместимость `LEGACY_SECTION`). Макет: `MeetApp.dc.html`, раздел `SETTINGS`
(`$MOCK` — см. план этапа 3). Пользователь одобрил этап заранее.

## Global Constraints

- Все ограничения этапа 3 (`docs/superpowers/plans/2026-10-09-0.4-stage3-main-window.md`,
  «Global Constraints») действуют и здесь, кроме запрета трогать `features/settings`
  — этот этап как раз его меняет.
- Ключи и семантика настроек не меняются: черновик, «Сохранить»/«Сбросить»,
  `PATCH /settings` только изменённых ключей, проверка перед сохранением,
  защита ухода с несохранёнными правками, точки «есть изменения» у разделов,
  мгновенные действия (автозапись, автозапуск, термины, токен HF, голос, модели,
  перенос движка, обновления) — как в 0.3.7. «Оформление» — без черновика (этап 1).
- Ни одна строка настроек 0.3.7 не теряется: каждая есть в новом разделе (или в
  его «Тонкой настройке»), с тем же названием или ясным новым; тест-индекс это
  проверяет.
- Подписи и подзаголовки — в обычном регистре (сейчас подзаголовки
  «РАСШИФРОВКА», «ПЛЕЕР» и т. п. — прописными: исправить).
- Плотность настроек — `data-density="compact"` на панели раздела (Aurora).
- Старые id разделов работают: `recording`, `sound`, `auto`, `asr`, `engine`,
  `export`, `assistant`, `analysis`, `categories`, `markup`, `diagnostics`,
  `about`, `advanced`, `appearance` → новые (`LEGACY_SECTION`): `recording`→`app`,
  `markup`→`analysis`, остальные — одноимённые, если раздел остался. Глубокие
  ссылки: трей `{section:"assistant"}`, карточки `onOpenSettings(...)`,
  `StorageNotices` → `"engine"`, событие оболочки `open-section`.
- Параллельные этапы в том же worktree возможны: коммитить только свои файлы
  явными путями.

## Группы и разделы (из спека)

| Группа | Раздел (id) | Состав (откуда) |
| --- | --- | --- |
| Общее | Оформление (`appearance`) | как есть (этап 1) |
| | Приложение (`app`) | автозапуск, уведомления, «Ваше имя в расшифровке», «Расшифровывать сразу после записи», папка записей (из «Запись»); «Мастер первого запуска» (из «Движок и модели») |
| Запись | Звук (`sound`) | микрофон, звук собеседников, проверка (без «Мой голос») |
| | Автозапись (`auto`) | вкл/выкл; программы (звонки, мессенджеры, свои); браузеры; ожидание (ползунок 1–60 мин вместо поля) и мин. длительность; «Тонкая»: «Только если в заголовке окна сайт звонка», сайты звонков |
| Расшифровка | Распознавание (`asr`) | устройство, движок/модель (видеокарта/процессор), язык; «Тонкая»: «Уточнять время каждого слова» |
| | Спикеры (`speakers`) | токен Hugging Face (из «Движок и модели»), «Мой голос» (из «Звук»), порог узнавания, «Отмечать одновременную речь» |
| | Словарь (`dictionary`) | термины распознавания, исправления для будущих расшифровок |
| | Движок и модели (`engine`) | состояние, где хранить, модели (загрузка), папки моделей |
| ИИ | Модели ИИ (`models`) | провайдеры, модель Claude Code/OpenCode, локальная модель, прокси; «Тонкая»: «Локальную модель — через прокси» |
| | Ассистент (`assistant`) | участник встречи, профиль, как часто писать, расширенные возможности, база знаний (папка, карта, исключения); «Тонкая»: окно живой расшифровки, «Не отвлекать по умолчанию», прежний режим подсказок (участник выкл.: активность, модель подсказок, сколько держать) |
| | Анализ встречи (`analysis`) | анализировать автоматически; таблица «размечать / показывать»; плеер (кривая важности, подписи глав); улучшение автоматически; название; категория автоматически |
| Встречи | Категории (`categories`) | как есть |
| | Экспорт (`export`) | как есть |
| | Jira (`jira`) | ссылки на задачи, адрес, проекты, проект по умолчанию; «Тонкая»: шаблон ключа |
| Система | Дополнительно (`advanced`) | команда после записи, маркер видеокарты, запуск агента (вкладка «Агент», из «Ассистент») |
| | Диагностика (`diagnostics`) | как есть |
| | О программе (`about`) | как есть |

Таблица «Анализ встречи»: строки — Типы реплик (`analysis.types` / `transcript_view.types`),
Важность (`importance`/`importance`), Главы (`chapters`/`chapters`), Наблюдения
(`insights`/`insights`), Ссылки на задачи (`analysis.issues` / `transcript_view.jira` —
последнее редактируется и в «Jira»; в таблице — тот же ключ). «Показывать»
недоступно при выключенном «Размечать» (подсказка «Сначала включите разметку»).
