Выпуск **Meet** 0.3.5. Встречи можно раскладывать по своим группам, список
разбит на разделы по датам, у поиска появились условия, подсказки и панель
«Фильтры». Локальную модель можно подключить, просто выбрав её из списка,
и она надёжнее разбирает встречи.

## Главное

- **Группы встреч.** Слева под «Записи» теперь есть список групп: «Все
  записи», ваши группы с цветом и числом встреч, «Без группы».
  - Группу создают через «+ Новая группа», в меню «⋯» её можно
    переименовать, сменить цвет, поднять выше или опустить ниже, удалить.
    После удаления 8 секунд доступна кнопка «Отменить».
  - У встречи одна группа. Правый клик по встрече (или по нескольким
    выбранным) → «Переместить в группу ▸». То же есть в панели выбора:
    «В группу ▾» и «Убрать из группы».
  - Встречи можно перетащить мышью на группу в левой панели, а группы —
    переставить перетаскиванием.
  - Когда выбрана группа, поиск идёт внутри неё.
  - Категории остаются как были. Категория — тип встречи, её может ставить
    модель. Группа — проект, клиент или серия встреч, её выбираете вы.
- **Разделы по датам.** Список разбит на «Сегодня», «Вчера», дни недели,
  месяцы и годы. Разделы сворачиваются, а Meet запоминает, какие вы
  свернули. В меню раздела есть «Свернуть остальные» и «Только этот
  период».
- **Поиск с условиями.** В строку поиска можно писать условия, и они
  превращаются в метки:
  - `участник:Анна` — встречи, где была Анна. Можно добавить несколько:
    тогда были все.
  - `группа:`, `категория:`, `название:` — по группе, категории, словам в
    названии.
  - `дата:вчера`, `дата:5 окт`, `дата:с 1.09 по 15.09`, `после:`, `до:` —
    по датам. Понимаются «сегодня», «прошлая неделя», «сентябрь 2025» и
    обычные даты.
  - `есть:итоги`, `нет:анализ`, `есть:ассистент` — по тому, что уже сделано.
  - `дольше:30м`, `короче:1ч` — по длительности.
  - Подсказки при вводе предлагают участников, группы, категории и
    варианты даты.
- **Панель «Фильтры»** вместо строки категорий. В ней видно, сколько
  встреч в каждой категории и группе, у каждого участника, сколько встреч
  с итогами, анализом и ассистентом, по длительности и периоду. Клик по
  значению ставит ту же метку, что и ручной ввод.
- **Результаты поиска.** Совпадения подсвечиваются в названии и у
  участника, вверху — «Найдено: N встреч, M мест». Кнопка «Ещё совпадений:
  N» открывает встречу сразу с поиском. Поиск понимает больше падежей:
  «нового бюджета» находит «новый бюджет».
- **Быстрее и без потолка.** Раньше список показывал только последние 200
  встреч, теперь — все. Поиск по большой библиотеке стал в 8–100 раз
  быстрее.
- **Локальная модель.**
  - Достаточно указать адрес сервера (Ollama, LM Studio, vLLM, llama.cpp
    и др.), а модель выбрать из списка. Если сервер не отвечает, моделей
    нет или адрес не тот, Meet объясняет это понятным сообщением.
  - «Проверить» показывает окно контекста модели.
  - Анализ, итоги, названия и ответы больше не обрезаются молча. Для Ollama
    Meet сам задаёт модели нужное окно. Для других серверов он нарезает
    встречу под окно модели. Если модель всё же видела только часть
    текста, в карточке так и написано.
  - Если окно меньше 6K токенов, анализ сразу отказывается и объясняет
    причину, а не сохраняет пустой результат. Из-за этого у встреч не
    появлялись главы и важность на шкале плеера.
  - Итоги длинной встречи на локальной модели собираются по частям,
    прогресс виден: «Итоги: часть 3 из 14».
  - Работают модели, которые сначала «рассуждают» (Qwen3, DeepSeek-R1,
    gpt-oss).
  - Новая настройка «Локальную модель — через прокси».

## Исправления

- macOS 13.0–13.2: окно Meet снова открывается.

## Обновление с 0.3.4

- Mac и Windows обновляются из приложения, как обычно. На Mac разрешения
  сохраняются.
- Ваши категории и их фильтр сохраняются. Строку категорий над списком
  заменила панель «Фильтры».
