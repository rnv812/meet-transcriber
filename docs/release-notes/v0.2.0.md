Первый публичный выпуск **meet** — приложения для Windows, которое записывает
созвоны и расшифровывает их на вашем компьютере: распознаёт речь, делит её по
спикерам и узнаёт знакомые голоса.

## Что это

meet живёт в трее и сам начинает запись, когда начинается звонок — в Zoom,
Microsoft Teams, Яндекс Телемосте, Dion, Webex, мессенджерах или в браузере.
Пишутся две дорожки: ваш микрофон и звук собеседников, без ботов в звонке и
виртуальных кабелей. После звонка запись расшифровывается локально, на
видеокарте NVIDIA или на процессоре. Итоги, ответы на вопросы и агент по
встрече работают через вашу подписку Claude Code или Codex; пока вы не
обращаетесь к модели, записи и расшифровки не покидают компьютер.

## Главное

- **Расшифровка с именами.** Whisper large-v3, дообученная на русском (на
  процессоре — Whisper medium), выравнивание по словам и разделение на
  спикеров (pyannote). Назовите человека один раз — дальше он узнаётся по
  голосу сам.
- **Панель «Спикеры».** Подсказки по голосу, отмена и история правок,
  исправление отдельных реплик, «Разделить спикера» по голосу и
  «Переразделить на спикеров» — без повторного распознавания речи.
- **Автозапись** звонков в приложениях и браузере; обрыв связи и перезаход
  не делят встречу на части, а минуты ожидания в конце обрезаются.
- **Библиотека встреч:** плеер, поиск по всем расшифровкам, объединение
  записей одной встречи, экспорт в Markdown, TXT и SRT.
- **Ассистент:** итоги (решения, задачи «кто · что · срок», открытые вопросы),
  вопросы по встрече с таймкодами, живая панель по ходу звонка и вкладка
  «Агент» — Claude Code или Codex в терминале прямо в папке встречи.
- **База знаний:** выгрузка встреч, например, в хранилище Obsidian — папка на
  встречу по шаблону.
- **Командная строка `meet`** и локальный API — для скриптов и агентов.

## Установка

1. Скачайте `meet_0.2.0_x64-setup.exe`. Контрольная сумма — в
   `SHA256SUMS.txt`; проверить: `certutil -hashfile meet_0.2.0_x64-setup.exe SHA256`.
2. Запустите установщик. Права администратора не нужны: программа ставится в
   `%LOCALAPPDATA%\meet`.

> **Windows SmartScreen.** Установщик не подписан сертификатом, поэтому
> Windows покажет «Система Windows защитила ваш компьютер». Нажмите
> **Подробнее** → **Выполнить в любом случае**. Это предупреждение о
> неизвестном издателе, а не о найденной угрозе.

3. При первом запуске откроется мастер. Он скачает **движок расшифровки**:
   для видеокарты NVIDIA — около **4,5 ГБ** (на диске нужно 8 ГБ свободного
   места), для процессора — около 0,6 ГБ (3 ГБ места). Затем модели
   распознавания — ещё до 4,5 ГБ. Прерванная установка при повторе
   докачивает только недостающее.
4. Для разделения на спикеров нужен бесплатный **токен Hugging Face** с
   правом чтения и принятые условия модели
   [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1)
   — мастер проведёт по шагам. Без токена расшифровка работает, но реплики
   делятся только на «Вы» и «Собеседник». Токен хранится в диспетчере учётных
   данных Windows.

Следующие версии ставятся поверх: новым установщиком или кнопкой «Настройки →
О программе → Проверить обновления». Записи, голоса и настройки сохраняются.

## Приватность

- **Всегда локально:** запись, расшифровка, разделение на спикеров, база
  голосов, поиск и экспорт. Служба записи принимает запросы только с этого
  компьютера (127.0.0.1, по токену).
- **Модель — только по вашей просьбе.** Текст встречи уходит выбранному
  провайдеру (Claude Code — в Anthropic, Codex — в OpenAI), когда вы делаете
  итоги, задаёте вопрос или ведёте запись с ассистентом. С локальным
  OpenAI-совместимым сервером текст не покидает компьютер.
- **Сеть** нужна для установки движка (Python, PyPI, download.pytorch.org),
  загрузки моделей с Hugging Face и — только по кнопке — проверки обновлений
  на GitHub. Телеметрии нет.

## Известные ограничения

- Только Windows 10 и 11 (x64). Версии для Linux и macOS в планах.
- Установщик не подписан — см. SmartScreen выше.
- Интерфейс на русском языке; распознавание настроено на русскую речь.
- Разделение на спикеров требует токена Hugging Face.
- Итоги, вопросы и агент требуют установленного и авторизованного Claude Code
  или Codex (или локального OpenAI-совместимого сервера).

## Лицензия

Apache-2.0. Авторы и сторонние компоненты (FFmpeg, uv, шрифт Onest, модели и
их лицензии) — в файле NOTICE; модели скачиваются с Hugging Face и
распространяются по своим лицензиям.

## Если у вас была тестовая версия 0.1.x

0.2.0 ставится поверх 0.1.0 и 0.1.1: установщик предложит «Обновить до
0.2.0», записи, голоса и настройки сохранятся. Не меняйте при этом папку
установки. Что изменится сразу:

- **Ожидание повторного подключения — 10 минут у всех** (настраивается от 1
  до 60), а минуты ожидания в конце автозаписи обрезаются: остаются
  30 секунд после конца звонка.
- **Выгрузка в базу знаний включится сама, если была задана папка заметок**:
  она становится «Папкой для встреч». Выключается в «Экспорт встреч».
- **Claude Code и Codex ходят через системный прокси Windows**; «Без прокси» или
  свой адрес — в разделе «Ассистент».
- **Вместо «Кто это?» — панель «Спикеры».** Старые расшифровки открываются в
  ней как есть; чья реплика с микрофона, у старой записи определяется по
  подписи владельца, а при «Разделить» и «Переразделить» — по звуку обеих
  дорожек.
- **Список программ звонков не меняется**: конфиг 0.1.0 без сохранённого
  списка остаётся на прежнем наборе (с Webex).
- Версия 0.1.0 ещё не умеет выходить по просьбе установщика: он закроет её
  после вашего OK и дождётся сохранения идущей записи.

### Спикеры

- **Панель «Спикеры»** (кнопка «Спикеры (N)» в карточке): доли времени,
  характерные фразы с ▶, подсказки «Похож на» из базы голосов, «Назначить…»,
  «Объединить с…», «Запомнить голос». Правки применяются разом и
  отменяются: «Отменить», «Повторить» (Ctrl+Z, Ctrl+Shift+Z), «История
  изменений» с возвратом к любому шагу.
- **Исправление отдельных реплик:** щелчок по имени на реплике («Только эта
  реплика» / «Эта и следующие подряд»), выделение Ctrl- и Shift-щелчком,
  «Разделить реплику здесь» правым щелчком по тексту.
- **«Разделить…»** — развести реплики спикера, в которого слились двое, по
  голосу (2–5 групп или по образцам из базы) без повторной расшифровки.
- **«Переразделить на спикеров…»** — заново только разделение на спикеров с
  числом собеседников и чувствительностью; текст и имена, данные вручную,
  остаются.
- **Порог узнавания голоса** — общий в «Настройки → Распознавание» и свой для
  встречи в панели.
- Переименование и слияние людей в «Голосах» переходит во все встречи вместе
  с их голосами.

### Прокси для подключения к моделям

- Ошибка «Request not allowed» (403) за VPN или корпоративным прокси больше не
  мешает итогам, вопросам и живому ассистенту: Claude Code, Codex, загрузка
  движка и моделей получают адрес прокси из настроек Windows.
- Настройка «Прокси для подключения к моделям» в разделе «Ассистент»: «Как в
  системе» (по умолчанию), «Без прокси» или «Свой адрес…» (`http://`,
  `https://`, `socks5://` с портом). Локальные адреса идут в обход прокси.
- Автоматическая настройка прокси (PAC-файл) не поддерживается — в этом случае
  укажите адрес вручную.

### Экспорт встреч в базу знаний

- Раздел настроек «Экспорт встреч»: для каждой встречи — своя папка по шаблону
  имени (по умолчанию «2026-09-30 - Название встречи», «/» создаёт вложенные
  папки) с транскриптом и итогами, по желанию — субтитрами и аудио. В
  карточке — кнопка «В базу знаний».
- Автоматическая выгрузка после расшифровки и ещё раз, когда готовы итоги, —
  если задана папка для встреч.
- Файл, изменённый вами в базе знаний, не перезаписывается.
- Заметки версии 0.1.0 остаются на месте: новая папка встречи создаётся рядом.
- «Папка заметок» стала «Папкой для встреч»; кнопка «В заметки» во вкладке
  «Итоги» заменена кнопкой карточки «В базу знаний».
- `meet kb-export <запись>` выгружает встречу из командной строки; прежняя
  `meet notes` работает как её синоним.

### Звук и программы звонков

- Раздел «Звук»: «Микрофон» и «Звук собеседников (вывод)» — «Как в системе»
  или конкретное устройство, кнопка «Проверить».
- Программы звонков — из готового списка (Zoom, Microsoft Teams, Яндекс
  Телемост, Dion, Webex, мессенджеры) плюс свои из запущенных.
- Звонки в браузере: звонком считается микрофон, занятый браузером не меньше
  15 секунд; по желанию — только если в заголовке окна сайт звонка.

### Автозапись: ожидание и обрезка

- «Ждать повторного подключения, мин» — от 1 до 60, по умолчанию 10.
- Если вы не вернулись, из записи до расшифровки вырезаются минуты ожидания:
  остаются 30 секунд после того, как пропал сигнал звонка. Записи, начатые
  вручную, не обрезаются.

### Объединение встреч

- Несколько записей одной встречи объединяются кнопкой «Объединить» (выделение
  Ctrl- или Shift-щелчком): звук склеивается по времени, встреча
  расшифровывается заново целиком, на стыках — «— перерыв N мин —».
- Исходные записи удаляются после успешной расшифровки объединённой, если не
  отмечено «Сохранить исходные записи».
- `meet merge <запись> <запись>… [--keep]` — то же из командной строки.

### Поиск и переименование

- Поиск по названиям и тексту всех встреч с фрагментами реплик; учитывает формы
  слов, фразы в кавычках и `спикер:Имя`.
- Ctrl+F в карточке — поиск по расшифровке: «N из M», переход стрелками.
- Переименование из списка: меню записи, двойной щелчок или F2; папка
  выгруженной встречи переименовывается следом.

### Настройки, подсказки и плеер

- Подсказки «?» у сложных настроек, тексты настроек переписаны понятным языком.
- Плеер работает сразу: длительность, перемотка, скорость до 2×; слышны обе
  стороны разговора.

### Вкладка «Агент»

- Claude Code или Codex во встроенном терминале в папке встречи, рядом —
  `transcript.md` и `summary.md`. Codex, установленный через npm
  (`codex.cmd`), во вкладке не запускается — нужна программа `codex.exe`.

### Обновление

- Установщик предлагает «Обновить до Y» (для той же версии — «Переустановить»,
  для более ранней — «Откатиться»), закрывает приложение штатно и ждёт, пока
  сохранится идущая запись.
- «Проверить обновления» в «Настройки → О программе»: проверка только по
  кнопке, скачивание установщика со сверкой контрольной суммы.
- Прерванные обрезка, расшифровка, импорт или объединение продолжаются после
  перезапуска (для записей за последние 7 дней).
- Галочка деинсталлятора «удалить данные приложения» переименована в «Удалить
  кэш окна»: она и раньше не трогала записи, голоса и настройки.

### Исправления

- Удаление записи больше не оставляет её наполовину удалённой, если папку
  держит другая программа.
- Удаление записи во время выгрузки в базу знаний больше не вызывает
  уведомление об ошибке.
- Итоги и объединение, завершившиеся одновременно с переименованием встречи,
  больше не теряют новое название.
- Две копии приложения с разными папками данных больше не занимают один порт.
