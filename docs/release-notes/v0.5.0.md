Выпуск **Meet** 0.5.0 — доводка после 0.4 по отзывам. Интерфейс стал плоским и
спокойнее: сияние осталось только на пустых экранах и в мастере первого запуска,
красный — только для ошибок. Плеер всегда внизу карточки, окно ассистента — две
колонки во всю высоту, у ассистента своя кнопка на рейке. Ассистент открывает
файлы и ссылки по просьбе, кнопки в его ответах можно нажать голосом, а согласие
«до конца встречи» даётся на действие с конкретным объектом. Запись больше не
ловит звук самого Meet — например, плеер старой записи. В «О программе» можно
поставить любую версию, в том числе откатиться.

## Главное

- **Плоский интерфейс.** Без свечения, бликов и градиентов — кроме сияния на пустых
  экранах и в мастере первого запуска. Карточки ИИ отмечены тонкой полосой слева,
  ответ ассистента — простая карточка, как у вашего сообщения.
- **Красный — только ошибки.** Отсутствующие модели и компоненты — нейтральные или
  янтарные метки, счётчики — по одному правилу: обычный, «новое» и «нужно решение».
- **Плеер всегда внизу.** Страница карточки не прокручивается — прокручивается
  только расшифровка, перемотка её не сдвигает. Волна — с контуром и полупрозрачной
  заливкой, над ней — риски важных реплик (щелчок — к реплике), скорость — меню
  0,75–2×.
- **Окно ассистента — две колонки во всю высоту.** Слева расшифровка до самого
  низа, справа чат с полем ввода внизу; у каждой колонки своя прокрутка и «↓ N
  новых». Профиль, частота и «Разрешено: N» — в шапке, «Что я знаю» — только
  справка.
- **Своя кнопка ассистента на рейке.** Во время записи под кнопкой записи —
  «Включить ассистента» (рабочая встреча или личный), а когда он работает —
  «Ассистент»: показать окно или выключить. Красная кнопка записи — только
  остановка.
- **Панель ассистента.** Рядом с индикатором записи — подписанная кнопка «Стоп»,
  ✕ только прячет окно (запись и ассистент продолжают работать), вернуть его —
  «Показать окно ассистента».
- **Картинки в чате открываются поверх окна:** щелчок мимо или Esc — закрыть,
  «Открыть файл», «Показать в папке».
- **Диалоги:** кнопки всегда в одну строку, на кнопке — само действие, а не «ОК».
- **Поиск по настройкам** подсвечивает найденное спокойно и коротко, совпавшие
  слова — жирным.
- **Перестановки в настройках.** «Ваше имя в расшифровке» — в «Спикерах», рядом с
  «Мой голос»; «Расшифровывать сразу после записи» — в «Распознавании». Мастер
  первого запуска можно пройти заново из «Дополнительно».
- **«Спикеры → Ваш микрофон».** Переключатели «Различать голоса в микрофоне» (люди
  рядом с вами — отдельными спикерами, нужен образец «Мой голос») и «Убирать
  повторы соседа и эхо». Раньше они были только в `config.json`; оба включены.

## Ассистент

- **«Действует сам» вместо «Автомода».** Подсказка: обычные действия ассистент
  выполняет сам, рискованные — после вашего разрешения. В режиме подтверждений —
  «Спрашивает каждое».
- **Открывает файлы и ссылки по просьбе.** Свои инструменты Meet для Claude Code:
  открыть файл, показать в папке, открыть ссылку — сразу; запустить программу —
  только после «Разрешить». Из реплик встречи — ничего.
- **Пути в ответах — ссылки:** открыть в своей программе или показать в папке.
- **«Открыть настройку».** Ассистент знает настройки Meet (без секретов) и
  добавляет в ответ кнопку, которая открывает нужный раздел.
- **Итог хода.** Под действиями — строка «Выполнено N из M · не удалось: … —
  причина», щелчок ведёт к неудавшемуся. Ассистент заканчивает работу явным итогом.
- **Кнопки голосом.** Скажите надпись кнопки под последним сообщением почти
  дословно в течение 30 секунд — Meet засчитает нажатие, а 10 секунд его можно
  отменить. Слушается только ваш микрофон; выключается в настройках ассистента.
- **Согласие «до конца встречи» — на действие с объектом.** Тот же файл, тот же
  инструмент MCP с тем же объектом (задача, ссылка, путь), а не вся папка или весь
  сервер. Удаление и отправка наружу — каждый раз заново. Список разрешённого и
  «Отозвать» — в шапке.
- **Запрет на чтение — только настоящих секретов** Claude Code и Codex (учётные
  данные, настройки, история сеансов). Навыки, плагины и команды читать можно.
- **Уровень рассуждений рядом с моделью.** «Модели ИИ»: для Claude Code и для
  Codex — «по умолчанию» или свой уровень; текущий виден в шапке ассистента.

## Запись

- **Без звука самого Meet.** На Windows 10 2004 и новее системный звук пишется без
  звука окна Meet — плеер старой записи больше не попадает во встречу. Не
  получилось — запись идёт, как раньше, весь системный звук (строка в журнале).
  macOS — то же через ScreenCaptureKit (экспериментально).

## Версии

- **«О программе» → «Другие версии».** Выпуски с GitHub по кнопке: дата, начало
  заметок, «Что нового», «Установить эту версию». Перед откатом Meet спрашивает и
  сохраняет копию настроек, базы голосов и служебных файлов в папку `backups` в
  папке данных; записи не трогаются. Откат ниже 0.4 — с отдельным
  предупреждением. На macOS откат тоже ставится отсюда; если нужен пароль
  администратора, окно macOS прямо говорит, что возвращается более старая версия.

## Исправлено

- **Пропадающее сообщение ассистента.** Склейка с предыдущим сообщением решается в
  начале хода — текст больше не исчезает и не переезжает.
- **Условия использования спрашивались при каждом запуске**, если после
  переустановки движка работал прежний резидент той же версии. Оболочка теперь
  заменяет такой резидент, а принятие условий проверяет ответ.
- **«Поиск не удался: IndexError»** при поиске своего голоса — исправлено.
- **Временная встреча могла сохраниться** как обычная — вероятная причина та же
  (прежний резидент со старым кодом), и замена резидента её убирает.

## Совместимость

- Настройки 0.4 читаются как есть. Две строки настроек переехали в другие разделы
  — значения те же.
- Звук без Meet требует Windows 10 2004 (сборка 19041) или новее; выключить —
  переменная окружения `MEET_PROCESS_LOOPBACK=0`.

## Для разработчиков

- Тесты Python — параллельно (pytest-xdist, до 6 процессов): 37 минут → 3.
- Договор настроек: каждый ключ, который пишет окно, есть в схеме движка, у каждого
  ключа есть читатель, каждый проходит круг «PATCH → config.json → чтение».
- «Прокликивание» окна (`scripts/clickthrough.py`): все экраны в двух темах,
  снимки и отчёт с ошибками консоли.
- Подпись Authenticode в CI — по секретам GitHub (`WINDOWS_SIGN_PFX`,
  `WINDOWS_SIGN_PASSWORD`); без них шаг пропускается. Инструкция —
  `docs/signing-windows.md`.
- Страж обезличивания: стоп-лист внутренних имён по всем файлам репозитория.
- macOS в CI: полный набор тестов Python (для сведения) и проверка запуска.
