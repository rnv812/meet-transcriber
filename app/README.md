# app — оболочка meet

Плавающая панель и окно настроек. Логики записи здесь нет: всё, что умеет
приложение, оно делает через control API резидента (`meet.control`) — окно
показывает состояние и передаёт команды.

## Что где

```
panel.html / src/panel.tsx    плавающая панель: состояния, таймер, уровни, кнопки
index.html / src/window.tsx   окно настроек и диагностики
src/tokens.css                дизайн-система: цвета, типографика, примитивы
src/api.ts                    клиент control API (fetch + EventSource)
src/useResident.ts            подписка на резидента: SSE + страховочный опрос
src-tauri/                    оболочка: окно без рамки, трей, запуск резидента
```

## Дизайн

Язык — тот, что задал Linear: почти чёрная база с несколькими ступенями подъёма,
индиго-акцент, волосяные границы вместо теней-подложек, плотная типографика с
тесным трекингом, радиусы 4–12 px, переходы 120 мс. Премиальность здесь берётся
не украшениями, а точностью — все значения в `src/tokens.css`, и оба экрана
берут их оттуда.

Шрифт — **Onest** (переменный, OFL, с кириллицей), пакетом
`@fontsource-variable/onest`: файлы лежат локально и попадают в сборку, потому
что CSP оболочки блокирует шрифтовые CDN. Веса 510/560/590 берутся с оси
переменного шрифта. Системный Segoe UI Variable остался фоллбэком.

## Запуск

Нужны Node 20+ и Rust (MSVC-тулчейн на Windows).

```
npm install
npm run app          # Tauri: панель как окно поверх всех, трей, всё по-настоящему
```

Панель ищет резидента в `%LOCALAPPDATA%/meet/daemon.json`. Не нашла — покажет
это состояние и предложит запустить дежурного (`meet-tray --watch`).

### Только фронт, без Tauri

```
npm run dev          # http://localhost:5173/panel.html и /index.html
```

Из браузера файл с токеном прочитать нельзя, поэтому dev-сервер проксирует
`/api` и сам подставляет заголовок. Резидент должен быть **уже запущен**, когда
поднимается dev-сервер: `daemon.json` читается один раз при старте Vite.

В браузере панель выглядит как обычная страница: рамка окна, перетаскивание и
«поверх всех окон» — это Tauri, в вебе их нет.

### Сборка

```
npm run build        # tsc --noEmit + vite build → dist/
npm run app:build    # инсталлятор NSIS в src-tauri/target/release/bundle/
```

Иконки рисует `scripts/make_app_icons.py` (в репозитории лежат готовые PNG/ICO).

## Решения, которые стоит знать

- **Панель не берёт фокус** (`focus: false` в `tauri.conf.json`): она висит
  поверх встречи, ради которой существует, и не должна у неё фокус отбирать.
- **Вся шапка — зона перетаскивания**, включая промежутки между кнопками:
  обработчик сам смотрит, попал ли курсор в кнопку. Тащит явный вызов
  `startDragging()`, а не `data-tauri-drag-region`: атрибут Tauri обрабатывает
  сам, и вместе с вызовом на один mousedown приходило два запроса — окно не
  двигалось вовсе.
- **Права в `src-tauri/capabilities/default.json` обязательны.** В Tauri 2
  системные команды закрыты по умолчанию: без записи в capabilities окно нельзя
  ни потащить, ни спрятать, ни изменить его размер — вызов отвергается с
  указанием недостающего права. Свои команды (`endpoint`, `open_settings`,
  `start_resident`) прав не требуют.
- **Окно подгоняется под высоту панели** (`fitWindowTo`): окно прозрачное, и его
  лишняя высота видна дважды — тень обрезается краями окна в прямоугольник, а
  невидимая часть окна перехватывает клики по тому, что под ней.
- **Окно настроек объявлено в конфиге и создаётся скрытым.** Создавать webview
  на лету из команды нельзя: на Windows окна создаются в главном потоке, а
  команда приходит из рабочего — приложение падало целиком (exit -1). Крестик
  прячет окно, а не уничтожает.
- **Позицию окна помнит `tauri-plugin-window-state`**; при первом запуске
  панель ставится по центру у нижнего края.
- **Трей оболочки скромный** (показать панель, настройки, выход): иконку записи
  с длительностью держит резидент, и два одинаковых меню путали бы.
- **Тёмная панель без светлой темы** — сознательно: она читается поверх любых
  чужих окон одинаково. Окно настроек, наоборот, уважает тему системы.
- **CSP** разрешает `connect-src` только на 127.0.0.1: другого адреса у API нет.
