# app — окно и оболочка meet

Окно приложения (React + TypeScript, Vite, Vitest) и оболочка Tauri 2 (Rust).
Логики записи и расшифровки здесь нет: всё это делает резидент на Python
(`src/meet`), а окно показывает его состояние и шлёт команды через control API
(`meet.control`, HTTP + SSE на 127.0.0.1).

Как поставить зависимости, запустить приложение из исходников, прогнать тесты
и собрать установщик — в разделе [«Разработка»](../README.md#разработка)
корневого README.

## Что где

```text
live.html, src/live/          плавающая панель живого ассистента (окно `live` оболочки)
src/app/                      каркас окна: навигация, индикатор записи
src/features/recordings/      список записей, поиск, импорт перетаскиванием
src/features/card/            карточка встречи: плеер, расшифровка, итоги, вопросы, агент
src/features/card/speakers/   панель «Спикеры»: имена, подсказки, история правок, разделение
src/features/voices/          база голосов: люди, аватары, переименование и слияние
src/features/settings/        настройки, диагностика, движок
src/features/wizard/          мастер первого запуска
src/features/hf/              токен Hugging Face
src/lib/                      клиент control API (api.ts), типы, форматирование, поиск
src/state/                    подписка на резидента (SSE + страховочный опрос), библиотека, люди
src/ui/, src/theme/           общие компоненты и дизайн-токены (шрифт Onest, OFL 1.1)
src-tauri/                    оболочка: трей, окна, запуск резидента, движок, обновления,
                              терминал агента (PTY), установщик NSIS (windows/hooks.nsh)
```

## Окно без Tauri

```powershell
npm run dev        # http://localhost:5173/ и /live.html
```

В браузере файл с токеном резидента прочитать нельзя, поэтому dev-сервер
проксирует `/api` на резидента и сам подставляет токен. Адрес он берёт из
`daemon.json` в `MEET_DATA_DIR` (иначе — из `%LOCALAPPDATA%\meet`) один раз при
старте: резидент должен быть уже запущен, а после его перезапуска dev-сервер
нужно перезапустить. Трея, рамки окна и терминала агента в браузере нет — их
даёт оболочка.

## Несколько решений, которые стоит знать

- **Права в `src-tauri/capabilities/default.json` обязательны.** В Tauri 2
  системные команды закрыты по умолчанию: без записи в capabilities окно нельзя
  ни потащить, ни спрятать — вызов отвергается с указанием недостающего права.
- **CSP** разрешает соединения только с локальной машиной: другого адреса у
  control API нет.
- **Установщик и данные живут в одной папке** (`%LOCALAPPDATA%\meet`):
  установщик и деинсталлятор вправе удалять только свои файлы. Это проверяет
  `scripts/nsis_tripwire.ps1` при каждой сборке выпуска.
